OrbitAdmin

Mission control for your server. Futuristic Bootstrap 5 admin panel with a pluggable backend.

Live demo View on GitHub
PHP 7.4 to 8.6 Bootstrap 5.3 MIT licensed JSON, SQLite, MySQL

Why OrbitAdmin?

Three backends, one interface

Switch between JSON, SQLite, and MySQL by editing a single line in config.php. The same modules work everywhere.

Security baseline

CSP with per-request nonce, HSTS, bcrypt cost 12, CSRF double-submit, rate-limited login, hash-chained activity log.

Install wizard + CLI

Run php bin/orbit install or visit /install. Either route prepares the DB, creates the admin user, and locks itself.

Mobile-friendly

Glassmorphism UI with command palette (Ctrl+K), dark/light toggle, off-canvas sidebar, and prefers-reduced-motion aware animations.

Built for ops

Users, roles, activity log, API tokens, email templates, file manager, system info, and settings ship in v1.

Modular

Every PHP file stays under 500 lines. Drop a folder under modules/ to add a new feature.

Quick start

git clone git@github.com:master3395/OrbitAdmin.git
cd OrbitAdmin
php bin/orbit install
# or open /OrbitAdmin/install in your browser

Demo credentials on the live site: admin / OrbitDemo!2026 (read-only seeded admin).
